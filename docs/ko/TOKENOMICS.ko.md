# AI Trade Bot (ATB) 토크노믹스 v1.0

> 이 문서의 모든 수치는 `scripts/deploy.js`의 `ALLOCATIONS`와 `contracts/AITradeBot.sol`의 상수에 그대로 들어가 있습니다. 문서와 코드가 어긋나면 코드가 진실이며, 그 경우 문서가 틀린 것입니다.

## 1. 원칙

1. **공급 고정.** 총발행 1,000,000,000 ATB. 민트 함수가 존재하지 않으므로 누구도 추가 발행할 수 없습니다.
2. **디플레이션.** 슬래싱된 보증금은 100% 소각됩니다. 모든 프로토콜 수수료 중 최소 30%는 코드가 강제로 소각합니다.
3. **공개 판매 없음.** 프리세일, ICO, IDO를 하지 않습니다. 토큰을 얻는 방법은 DEX 매수, 바운티 보상, 커뮤니티 프로그램, 파트너 그랜트 네 가지입니다.
4. **모든 락업은 온체인.** 팀·재단·파트너 물량은 취소 불가능한 베스팅 컨트랙트에 배포 시점에 전액 예치됩니다. "나중에 락하겟다"는 약속이 아니라 배포 트랜잭션 안에서 실행됩니다.
5. **관리자 권한은 상한이 있음.** 오너가 바꿀 수 있는 값은 수수료율과 최소 보증금뿐이고, 각각 코드에 박힌 최댓값을 넘을 수 없습니다. 블랙리스트, 주소별 세금, 전송 제한 기능은 없습니다.

## 2. 배분

| 배분 | 비율 | 수량 (ATB) | 클리프 | 총 베스팅 기간 | 수령 지갑 |
|---|---|---|---|---|---|
| 유동성 (PancakeSwap LP) | 20% | 200,000,000 | 없음 | 즉시, LP 토큰 12개월 외부 락 | 재단 멀티시그 |
| 커뮤니티·바운티 풀 | 35% | 350,000,000 | 없음 | 36개월 선형 | 재단 멀티시그 |
| 생태계·파트너 | 15% | 150,000,000 | 6개월 | 30개월 선형 | 재단 멀티시그 |
| 팀 | 15% | 150,000,000 | 12개월 | 5%(750만)는 TGE 즉시 해제, 나머지 1억 4,250만은 48개월 선형 | 팀 지갑(하드웨어 또는 멀티시그) |
| 재단·운영 | 15% | 150,000,000 | 6개월 | 30개월 선형 | 재단 멀티시그 |
| **공개 판매** | **0%** | 0 | | | |

- 베스팅은 TGE(배포 시점)부터 계산합니다. 클리프 이전에는 0, 클리프 시점에 그때까지 누적된 선형 물량이 한 번에 풀리고, 이후 초 단위 선형입니다.
- 배포 직후 베스팅 컨트랙트의 오너 권한은 포기(renounce)되어 새 스케줄을 만들거나 기존 스케줄을 바꿀 수 없습니다.
- 유동성 물량은 풀 생성에 쓰이며 LP 토큰은 외부 락 서비스에 12개월 잠금 후 링크를 공개합니다.

## 3. 수요와 소각 구조

| 흐름 | 누가 내나 | 얼마 | 소각 | 재단 |
|---|---|---|---|---|
| 봇 사용료 (`payAccess`) | 봇을 쓰는 사용자 | 요금제별 (오프체인 정의) | 50% | 50% |
| 봇 등록 수수료 | 봇 운영자 | 100 ATB (최대 1,000) | 50% | 50% |
| 바운티 수수료 | 바운티 지급액에서 | 2% (최대 5%) | 50% | 50% |
| 슬래싱 | 사고 낸 봇의 보증금 | 중재자 결정 | 100% | 0% |
| 보증금 락 | 봇 운영자 | 최소 1,000 ATB | 락 (유통량 감소) | |

**하드캡 (코드 상수):**

| 상수 | 값 | 의미 |
|---|---|---|
| `MIN_FEE_BURN_BPS` | 3,000 | 수수료 소각 비율 하한 30%. 오너는 올릴 수만 있음 |
| `MAX_BOUNTY_FEE_BPS` | 500 | 바운티 수수료 상한 5% |
| `MAX_REGISTRATION_FEE` | 1,000 ATB | 등록 수수료 상한 |
| `MAX_MIN_BOND` | 100,000 ATB | 최소 보증금 상한 |
| `MAX_PAUSE` | 7일 | 일시정지는 최대 7일 후 자동 해제 |
| `PAUSE_COOLDOWN` | 7일 | 일시정지 종료 후 다음 일시정지까지 최소 간격 |
| `UNBOND_DELAY` | 7일 | 보증금 회수 대기(분쟁) 기간 |

**투명성 카운터 (온체인 조회):** `totalBurned`, `totalTreasuryFees`, `totalAccessPaid`, `agentCount`, `totalAnchors`. 사이트 대시보드가 이 값을 그대로 표시합니다.

## 4. 재단 수입 사용 원칙

재단으로 들어오는 수수료의 용도는 공개 순서로 제한합니다.

1. 외부 감사, 버그 바운티 추가 재원
2. 인프라 (RPC, 인덱서, 대시보드 운영)
3. 유동성 보강
4. 개발 인력

재단 지갑은 Safe 멀티시그(3/5)이며, 분기별 지출 내역을 공개합니다.

## 5. 거버넌스 권한과 이전 계획

| 권한 | 현재 | 이전 목표 | 할 수 있는 것 | 할 수 없는 것 |
|---|---|---|---|---|
| `owner` | 배포자 → 즉시 Safe 3/5 | 2027 Q2 DAO | 수수료율(상한 내), 최소 보증금(상한 내), 중재자·재단 주소, 기한 있는 일시정지, 등록 에이전트 긴급 동결 | 민트, 블랙리스트, 베스팅 변경, 보증금 압류, 에이전트 일일 한도 변경, 동결 해제, 미등록 지갑 제한 |
| `arbiter` | 배포자 → 즉시 Safe 3/5 | 2027 Q2 분쟁 DAO | 등록 봇 보증금 슬래싱 (사유 온체인 기록) | 일반 지갑 자금 접근 |
| 베스팅 `owner` | 배포 직후 포기 | 없음 | 없음 | 모든 것 |

일시정지(pause)는 감사 전 사고 대응용입니다. 한 번에 최대 7일이며, 끝난 뒤 7일 동안은 다시 걸 수 없습니다. 감사 보고서 공개 후 Safe가 `disablePauseForever()`를 호출해 영구히 없앱니다. 오너 이전은 2단계로, 새 오너가 `acceptOwnership()`을 호출해야 완료됩니다.

## 6. 규제 관점 정리

- ATB는 봇 접근, 운영자 보증금, 바운티 지급에 쓰이는 **유틸리티 토큰**입니다.
- 배당, 수익 분배, 바이백 약속, 원금 보장이 **없습니다.** 컨트랙트에 그런 기능이 없고 앞으로도 추가하지 않습니다.
- 사용자 자금을 모으거나 대신 운용하지 않습니다. 봇은 사용자 본인의 거래소 계좌와 API 키로 동작합니다.
- 공개 판매를 하지 않으므로 특정 국가의 공모 규제 대상이 아니지만, 각국 세법과 가상자산 규제 준수 책임은 참여자에게 있습니다. 한국 거주자는 가상자산이용자보호법과 소득세법의 가상자산 과세 일정을 확인해야 합니다.

## 7. 검증 방법

누구나 아래를 확인할 수 있습니다.

```
token.totalSupply()          == 1,000,000,000 * 1e18   (민트 함수 없음)
vesting.totalLocked()        == 베스팅 배분 합계 (792,500,000 * 1e18 at TGE)
vesting.owner()              == 0x0  (포기됨)
token.MIN_FEE_BURN_BPS()     == 3000
token.MAX_BOUNTY_FEE_BPS()   == 500
token.MAX_REGISTRATION_FEE() == 1000 * 1e18
```

배포 시 `deployments/<network>.json`에 모든 수령 주소와 스케줄이 기록되어 저장소에 커밋됩니다.
