# AI Trade Bot (ATB) 백서 v0.1

## 1. 문제
AI 에이전트가 지갑을 들고 자율적으로 거래·결제·계약을 실행하는 시대가 시작됐다. 하지만 에이전트는 사람보다 훨씬 쉽게 속는다.
- 프롬프트 인젝션 한 줄로 지갑 전액이 빠져나갈 수 있다.
- 상대 에이전트가 누구 소유인지, 사고 이력이 있는지 확인할 방법이 없다.
- 사고가 나도 책임을 물을 온체인 장치가 없다.

## 2. 해법
ATB는 에이전트 지갑에 **한도·킬스위치·보증금**을 붙이는 BEP-20 토큰이다.

| 기능 | 설명 | 보안 효과 |
|---|---|---|
| 에이전트 등록 | 에이전트 지갑이 운영자를 승인한 뒤, 운영자가 메타데이터 해시 + 보증금과 함께 등록 | 신원 확인, 동의 없는 등록 불가 |
| 일일 전송 한도 | 등록 에이전트는 24h 내 정해진 ATB까지만 전송 가능 | 해킹 피해 상한 |
| 킬스위치 | 운영자·오너가 즉시 동결, 해제는 운영자만 | 사고 즉시 차단 |
| 슬래싱 | 중재자가 보증금 삭감 → 소각 | 책임 강제 |
| 온체인 평판 | min(보증금/100 ATB, 100) + 등록 일수 + 앵커 수/10 − 누적 슬래싱당 100 | 상대 에이전트 신뢰 판단, 보증금만으로 높은 점수 불가 |
| 바운티 에스크로 | 취약점 보상을 락업 후 지급 | 보안 연구 유인 |

## 3. 토크노믹스
상세 스펙은 [TOKENOMICS.md](TOKENOMICS.md)에 있으며, 모든 수치는 배포 스크립트와 컨트랙트 상수에 그대로 들어 있다.

- 총발행: 1,000,000,000 ATB. 민트 함수가 없어 추가 발행 불가. 슬래싱은 100% 소각, 프로토콜 수수료는 최소 30% 소각(코드 강제).
- 공개 판매 없음. 프리세일·ICO·IDO를 하지 않는다.
- 팀·재단·파트너 물량은 배포 트랜잭션 안에서 취소 불가능한 베스팅 컨트랙트에 전액 예치되고, 베스팅 관리자 권한은 즉시 포기된다.
- 최소 보증금: 1,000 ATB. 등록 수수료 100 ATB(상한 1,000), 바운티 수수료 2%(상한 5%), 봇 사용료는 50% 소각·50% 재단.

| 배분 | 비율 | 수량 | 클리프 | 베스팅 |
|---|---|---|---|---|
| 유동성 (PancakeSwap) | 20% | 2억 | 없음 | LP 토큰 12개월 락 |
| 커뮤니티·바운티 풀 | 35% | 3.5억 | 없음 | 36개월 선형 |
| 생태계·파트너 | 15% | 1.5억 | 6개월 | 30개월 선형 |
| 팀 | 15% | 1.5억 | 12개월 | 5% TGE 즉시, 95% 48개월 선형 |
| 재단·운영 | 15% | 1.5억 | 6개월 | 30개월 선형 |
| 공개 판매 | 0% | 0 | | |

## 4. 공개 트랙레코드
- 체결 순간 거래 해시를 온체인에 기록하고, 거래 내용은 포지션 청산 24시간 뒤에 사이트에 공개한다. 열린 포지션과 최근 청산은 해시만 보인다.
- 따라서 실시간 시그널이 아니라 지난 거래 기록이다. 매매 추천이나 투자 자문이 아니다.
- 브라우저가 각 기록의 sha256을 다시 계산해 앵커된 해시와 맞추고, 해시 체인을 온체인 `anchorHead`와 비교한다. 각 앵커를 트랜잭션 영수증에서 직접 확인할 수도 있다.
- 결과는 거래별 수익률(%, 수수료 차감)만 보여준다. 계좌 규모나 금액은 공개하지 않는다.
- 코인만 공개한다. 다른 시장의 체결은 해시만 남겨 체인 검증은 유지하고 내용은 공개하지 않는다.

## 5. 로드맵
각 단계는 앞 단계 조건을 충족해야 진행한다. 조건이 안 되면 일정이 밀린다.
- Q4 2026: 레퍼런스 봇이 BSC 테스트넷에 코인 실거래를 모두 앵커. 사이트에 공개 트랙레코드(청산 24시간 후 공개)
- Q1 2027: 실거래 기록 3개월. 무료 대시보드. 기록과 수요가 뒷받침되면 유료 요금제를 달러 결제로 시작
- Q2 2027: 실거래 기록 6개월 → 외부 감사 → 법률 검토. 그 뒤에만 BNB 메인넷, PancakeSwap 풀(LP 12개월 락), ATB 결제, CMC/CoinGecko 등록
- 이후: 외부 봇 보증금 등록, 중재자 멀티시그 → 분쟁 DAO, 감사 후 pause 영구 비활성화, 검증 API

## 6. 거버넌스·보안
- 오너 권한은 수수료율(상한 내)·최소 보증금(상한 내)·주소 변경·등록 에이전트 긴급 동결·기한 있는 일시정지(최대 7일, 7일 쿨다운, 영구 비활성화 가능)로 제한. 민트·블랙리스트·베스팅 변경 기능은 존재하지 않음
- 오너 이전은 2단계: 새 오너가 `acceptOwnership()`을 호출해야 완료
- 거래 앵커는 에이전트별 해시 체인(`anchorHead`)으로 기록되어 누락·순서 변경·수정이 드러남. 슬래싱 이력은 등록 해지 후에도 지갑에 남음
- `owner`, `arbiter`는 배포 직후 Safe 멀티시그(3/5)로 이전
- 슬래싱 기준은 공개 문서로 명문화, 모든 슬래싱은 사유가 온체인 이벤트로 기록
- 컨트랙트 감사 보고서는 사이트에 공개

## 7. 면책
ATB는 유틸리티 토큰이며 투자 상품이 아니다. 공개 트랙레코드는 검증을 위해 지연 공개하는 한 봇의 과거 거래 기록이며, 매매 시그널·추천·투자 자문이 아니다. 과거 결과는 미래를 보장하지 않는다. 각국 규제(한국 가상자산이용자보호법 포함)를 확인할 책임은 참여자에게 있다.
