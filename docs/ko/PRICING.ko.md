# AI Trade Bot 요금제 v1.0

> 결정일 2026-10-01. ATB는 결제 수단이며, 요금은 달러 기준으로 고정하고 결제 시점 ATB 시세로 환산합니다. 사용자는 자기 거래소 계좌와 API 키로 봇을 실행합니다. 우리는 자금을 보관하거나 운용하지 않습니다.

## 티어

| 티어 | 월 요금 (USD) | 포함 | 온체인 plan id |
|---|---|---|---|
| **Free** | $0 | 대시보드 조회, 봇 리더보드, 백테스트·벤치마크 실행, 온체인 트랙레코드 열람 | 없음 |
| **Standard** | $29 | 코인 봇 1개 실행(바이낸스), 텔레그램·웹푸시 알림, 손절·지갑 가드 | `keccak256("standard-monthly")` |
| **Pro** | $99 | 코인 봇 무제한, 전략 전체, 우선 지원, 신규 전략 조기 접근 | `keccak256("pro-monthly")` |

- 연간 결제는 2개월 할인 (10개월 요금).
- 봇 운영자(자기 봇을 등록해 남에게 공개하는 사람)는 요금제와 별개로 최소 1,000 ATB 보증금과 100 ATB 등록 수수료가 필요합니다.

## 결제 흐름

1. 사용자가 대시보드에서 티어 선택 → 백엔드가 현재 ATB/USD 시세로 결제 수량을 견적 (10분 유효).
2. 사용자가 `payAccess(agent, amount, planId)` 트랜잭션 전송. 50%는 소각, 50%는 재단.
3. 백엔드가 `AccessPaid(payer, agent, amount, plan)` 이벤트를 확인하고 payer 지갑에 30일 접근권 부여.
4. 대시보드 로그인은 지갑 서명(SIWE 방식)으로 payer 주소를 확인.

## 시세 소스

- 1차: PancakeSwap ATB/WBNB 풀 TWAP(30분) × Chainlink BNB/USD.
- 풀이 없는 테스트넷 단계: 고정 환율 1 ATB = $0.01 (테스트용, 문서와 UI에 명시).

## 규제 관점 메모

- 소프트웨어 구독료입니다. 수익 약속, 원금 보장, 수익 분배가 없습니다.
- 수수료 배분: 모든 결제의 50%는 소각, 50%는 트레저리로 갑니다(컨트랙트상 최소 30% 소각). Pro 한 달 $99를 내면 $49.50어치 ATB가 소각됩니다.
- 요금은 언제든 변경될 수 있으며, 변경은 다음 결제 주기부터 적용합니다.
